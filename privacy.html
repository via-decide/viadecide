Privacy Policy

Last updated: July 2026

The short version: The Alchemist app collects zero data from you. It runs entirely on your device. Nothing leaves your hardware. Ever.

01 // The Alchemist App

The Alchemist Android application is designed as an offline-first, privacy-native system. It requires no internet connection to function and transmits no data to any external server — including ours.

The app does not collect, store, or transmit:

  • Your learning history, session data, or quiz answers
  • Retention scores or progress metrics
  • Device identifiers, IMEI, or advertising IDs
  • Location data of any kind
  • Crash reports or usage telemetry
  • Any personally identifiable information

All data — curriculum, engine state, user progress — lives exclusively on your local device storage. Uninstalling the app removes everything.

02 // This Website (daxini.xyz)

If you submit a field report via the feedback form on this page, you voluntarily provide your name and a review message. This is stored in a local SQLite database on our private, self-hosted server infrastructure. It is used solely to improve the product. It is not sold, shared with, or processed by any third-party analytics or marketing services.

Your email address, if provided, is used only to respond directly to your report. We do not add you to any mailing list.

03 // Hosting & Server Logs

This site is served from a self-hosted server running on private infrastructure. We do not use Google Analytics, Mixpanel, Hotjar, or any third-party tracking scripts.

Standard server access logs (IP address, request path, timestamp) may be retained for up to 30 days for security monitoring and are then purged automatically.

04 // Amazon Book Links

Links to books on Amazon use an affiliate tag. Clicking these links may result in Amazon setting a cookie on your browser per their standard e-commerce practice. We have no access to this data. Refer to Amazon's own privacy policy for details.

05 // Changes

If this policy changes materially, the "Last updated" date above will be revised. Continued use of the app or website after any changes constitutes acceptance of the updated policy.
